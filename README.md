# Petra By Night

Frontend prototype. Run `npm install` and `npm run dev` to edit the source with Vite. The booking flow includes a preview button with sample dates. Visitor uploads stay in the browser. No payment processing is included.

## GitHub Pages

Enable GitHub Actions as the Pages source in Settings → Pages. Run **Deploy Petra demo** from Actions. The workflow publishes the included static `preview` directory with paths adjusted for this repository.
